# web-source-to-article 使用说明

把一个外部网页链接（论坛帖、问答、新闻、文章）转成 `docs/zhHans/` 下的一篇中文知识库文章。

## 这个技能会做什么

1. 抓取链接内容（Discourse 论坛只抓 `<url>.json`，一次拿到完整原帖和回复，不再抓 HTML 页面）。
2. 生成一个简体中文标题（点出具体情况和利害，不加 `案例：` 前缀）。
3. 选择最合适的存放路径（按内容领域映射到 `work-visas/`、`payroll-and-tax/` 等最精确的子目录）。
4. 写成 markdown：**忠实保留原文内容** ＋ 用 `<ReferenceSource>` 组件标注来源。

## 两个硬性检查（会停下来问你）

- **没给链接**：Claude 会直接问你要 URL，不会去猜或搜一个替代链接。
- **抓不到原文**：需要逐字保留的部分（原帖、方案、作者顾虑）如果只抓到摘要，
  Claude 会请你把原文贴出来，贴出来之前不会动笔。

## 怎么用

直接给 Claude 一个网址，并说明要据此生成知识库文章 / 专题 / 案例。例如：

```
把这个帖子整理成一篇文章：https://www.uscardforum.com/t/xxxxx
```

可选：同时指定希望的存放路径或切入角度；不指定时，路径不明确处 Claude 会先和你确认。

## 产出要点

- 忠实保留来源原文，不杜撰法条或个案结论。
- 文章自动进入侧边栏，无需手动注册。
- 不包含 `<LicenseNotice />`、`## 相关文章`、免责声明等区块。
- 省 token：最多读一篇相邻文章对齐格式；不跑 dev server；完成后只报告文件路径和摘要，不回显全文。
