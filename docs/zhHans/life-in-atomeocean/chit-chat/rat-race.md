# 老鼠赛跑

这篇文章可能会过于现实，我先不发小红书，以免传播太广带来麻烦，毕竟现在讲究积极正面，所以先看看公众号里读者的反馈再说。

现实生活中很多东西分析透了其实会让人变得悲观。比如说这段时间跟几个工作了的人交流，发现他们基本上都忙到没时间思考。而且这个不是个例。我可以预料到，这种忙的状态会持续很长一段时间。

举个例子，本科或者硕士毕业大概22-25岁，如果你在毕业的时候，发现家里没有因为你读大学或研究生欠下债的话，你已经好过不少同龄人。

然后你找到一份普通的工作，正常情况下初入社会工资不会太高。等职场菜鸟的你工作3-5年，好不容易把大学期间欠的债还清了。

本来以为可以缓一下，可是这个时候你发现到了谈婚论嫁需要成家的年纪。摆在你面前实实在在的问题是需要娶个老婆或者找个男人嫁了。小俩口再怎么商量，碍于面子总归得弄点房子车子结婚用。好吧，找银行贷了一大笔款，所以你又欠下不少债。

好在工作上你继续努力，也小有成就，升了个1-2级，当了高级员工，工资翻了一倍，你也表示满足。再干了3-5年，买房买车的贷款算是还得差不多，暂时没有太大压力。可猛然你发现你都30好几，这会儿得生小孩了。于是你调养身体，再换个房子，怀孕，生娃，养娃，开销一下子上来，之前涨的工资太不经花，于是你发现又要不停地连轴转。

再过几年，到30大几接近40，娃要上学，换个学区房，报几个培训班，正好父母年纪大了，各种病痛都来了，需要你照顾，这到了你事业上最辛苦的阶段。不过天公念在你的努力，让你终于升成了一个部门经理或者小主管，可惜涨的工资还不够你这几年额外的花销。终于到40不惑之年，你希望事业能够再上一个台阶，工资能再涨一些的时候，经济周期来了，大环境下行，职场中年危机，你的工资薪酬足够公司用来招聘好多刚毕业的大学生。而且那些年轻人恨不得住公司，没日没夜地拼命干，不像你一把年纪了，时不时请个病假做体检，还得提早下班陪小孩。你只能面临被淘汰的结果了。

这就是目前很现实和无奈的写照。有的家庭好点，各个节点上有外援的支持，比如说结婚买房父母能帮衬着点儿；有的家庭差些，下面还有弟弟妹妹需要你接济。

我猜会有人不赞同上面这种悲观的描述。他们会觉得，再怎么说还是有一份工作的，只要你乐观积极地看待，肯努力，肯拼，然后日子过得再省点儿，各方面都勒紧裤腰带，多省钱，生活总归是美好的。我不觉得这种认识是错的，因为绝大部分人的生活都是这个版本，我父母是这么过来的，我的大部分亲戚朋友也都是这么过来的。而且人的适应能力和容忍度都很强，小城市有小城市的过法，大城市有大城市的日子。月薪5千和月薪两万，90平3居室和150平大四房，都是过日子，不是么？

我不是在讨论这种生活好与不好。我只是在想指出来，你们有没有发现这说不定是一款游戏，而大部分游戏玩家的剧本都写好了的？比如说游戏巧妙地设计，每3-5年一个小关卡，每个关卡难度逐渐增加，然后游戏玩家的技能点也逐渐提升。比如说游戏规定，只要有一份工作，干得不好少点奖金，但是饿不着；拼了命去搞，升得快一些，赚得多点儿，但是也不比平均水平高太多。尤其是那些上进好学工作努力的，游戏会用一点点诱人的几千或者几万奖金，让你不断加班，忙到昏天黑地，卷得一塌糊涂。但是各个阶段，这几千或者几万块，又正好恰如其分地在你当下的处境让你觉得一切都是值得的。整体思路就是，游戏给你设置的关卡，难度，技能点，让你在这里面玩得不亦乐乎，欲罢不能，还为自己每一个阶段取得的成绩沾沾自喜。

然而，生活没有让你发现的是，整个游戏的逻辑里，你永远都是在用你的时间和精力换取回报：你干得多，多赚点；干得少，少赚点；哪天不干了，就没钱了。

这个时候你终于意识到，这个社会运行的的逻辑就是这样，基本大部分的人就是在这个既定的轨迹里。但是如果你现在开局装备太差（出生贫寒，家里又没托举，又不是学霸），那你很可能就会困在靠近底端的Rat Race里，日子相对过得艰辛一些。可问题是，你此刻又拥有着一颗躁动不安的，于是乎你就琢磨着，能不能在开局不好的情况下，跳出这个rat race（老鼠赛跑）的游戏呢？

答案是肯定的。我给你举一个我最近听到的很感人的例子。

Cyan Banister（中文译为“赛恩·巴尼斯特”）是硅谷号称从无家可归的流浪女孩，到硅谷最成功的女性天使投资人之一。她在最近一期Tim Ferriss Show里面谈到她悲惨的童年：出生在一个非常不稳定、充满暴力和忽视的家庭环境中长大。她的父母（尤其是母亲）经常虐待她，有时候还会锁她在房间里、不给她食物，甚至在心理上不断打击她的自信心。Cyan在成长过程中很少上学，几乎可以说是“半文盲”，青少年时期基本靠自己摸索学习。大约在14岁时，她彻底离开了家，变成了无家可归（homeless）的孩子，住在街头、朋友家的沙发、甚至是废弃的建筑物中。

相信读到这里，我的读者里没有任何一个人可以说自己的经历比Cyan更加的艰苦，开局比她更差。但这也就是为什么她的故事感人的地方。Cyan的转折和救赎来自于她在流浪期间，她靠在公共图书馆、朋友家蹭电脑，一点一点自学编程和互联网技术。她做过各种低薪工作，比如宠物护理员、技术支持人员，但她非常努力，抓住一切机会自学提升。她后来进入了Tech Support领域工作，并逐渐结识了一些硅谷创业圈的人。她最早参与了early web community的一些论坛，比如Slashdot，积累了人脉和名气。认识了当时的一些天使投资人和创业者，比如Peter Thiel圈子的人。她用自己攒下来的积蓄开始进行小额投资，第一批投资就包括Uber、SpaceX、DeepMind等传奇公司，因此彻底改变了自己的人生轨迹。后来，Cyan成为了Founders Fund（Peter Thiel创办的著名风险投资公司）的第一位女性合伙人。

在Tim Ferriss的那期访谈里，Cyan特别强调了几个理念：1. 自学能力：即使你没有正规教育，只要有决心，你可以通过阅读、观察和实践学会一切。2. 相信自己，不听消极的人：即使身边人不支持你（甚至不断打击你），你也要给自己找到价值感。3. 勇于接受帮助但不依赖：她在街头流浪时，有好心人帮过她，但她始终坚持靠自己走出困境。4. 保持好奇心：她说，“我能走到今天，最大的资产就是我对世界的无尽好奇心。”

这种例子还不在少数。我最喜欢的All-In podcast里面，Chamath Palihpitiya 出生于斯里兰卡，6岁时移民到加拿大，家境非常贫困。他父亲失业、家里依赖政府救济金生活。Chamath小时候主要靠自己打工、半工半读完成学业。成长过程充满了羞辱感与奋斗。Jason Calacanis出生于纽约布鲁克林的工人阶级家庭，父母都是蓝领，家里不富裕。他自己形容家里常常是"paycheck to paycheck"（勉强糊口）。他靠奖学金读大学，后来通过不断努力进入科技圈。还有很多这种人，Elon Musk，Howard Schultz（星巴克前CEO）等等都是如此。

所以现在看来，虽然生活和社会这个游戏默认设置就是Rat Race。但是还是有不少人成功出圈玩出了不一样的游戏结局。我大致观察总结了这些网上的例子，和我身边算是跳出圈的人，大概分为这几类：

1. 含着金钥匙出生，比如说X二代，这个X可以是官，富，矿，留，大学教授等等，他们一开局就不在Rat Race这个设置里面，所以也不在我们的讨论范围，
2. 小镇做题家，靠读书上了名校，学霸，给自己挣了个好前程，基本上在读书期间就跳出了Rat Race（我应该算这种）
3. 冒险者外加赶上时代红利，那些很早进腾讯，阿里，字节的，工作几年，拿住了股票，或者在某个节点赌对了行业，比如说，房地产，虚拟货币，跨境电商，然后发了一笔，也跳出了Rat Race，
4. 还有就是遇到了贵人，比如说嫁了个好人家，或者娶了个好老婆，或者像上面Cyan的这种，遇到了硅谷大佬的带飞，从此就出圈了。

除了这几个，我好像想不到其他的途径了（统计跟踪表明，中六合彩暴富的大部分最后都返贫了）。所以很多联系我的人，你如果手里的牌不怎么好，你又想将来过上自由的生活，那么你看看上面哪种更可能发生在你身上。我偷偷告诉你，你好好仔细看看3和4。

读到这里，我希望你明白了我想说的话，这款游戏有一些规则，你越早明白对你越有利。比如说你大学毕业后，回了老家四线城市的某一个暮气气沉沉，不温不火，鸡毛蒜皮的小单位待着，管事的和年长的都是半吊子水平，外加对着有大学文凭的年轻的你不怎么待见，周围还有很多大姑大婶撺掇着劝你找个对象嫁了算了。我可以很负责任地告诉你，你再怎么努力，拼搏，刻苦，坚毅，顽强，奋斗，勉励，不懈，忍耐，坚韧，不屈，百折不挠，自强不息，持之以恒，迎难而上，奋不顾身，拼搏进取，力争上游，披荆斩棘，不畏艰难，挥汗如雨，负重前行，一往无前，等等等等，都是无济于事的。

为什么呢，因为这个游戏的剧本都写好了的，只是你不相信而已。
