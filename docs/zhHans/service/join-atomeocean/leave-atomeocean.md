# 从Atomeocean离职的标准流程

## 1. 流程概述

退出Atomeocean组织需要完成以下关键步骤

1. 提交正式离职申请
2. 工作交接
3. IT资产归还
4. 账户权限回收
5. 发送确认邮件

## 2. 详细操作步骤

### 2.1 确定最后工作日
- 与直属领导确认最后工作日

### 2.2 工作交接
1. 整理并移交工作文档
   - 项目文件
   - 客户资料
   - 待办事项清单


### 2.3 IT资产归还

需归还的物品包括

- 笔记本电脑及电源
- 门禁卡/员工卡
- 公司手机（如配备）
- 其他外接设备（如配备）

### 2.4 系统权限回收
IT部门将处理

- 企业邮箱停用
- 云存储账户关闭

## 3. 必须发送的确认邮件

### 3.1 邮件发送要求
- 收件人：askhr@atomeocean.com
- 抄送：直属主管

邮件主题
```text
[Resignation Confirmation] [Your Full Name] - [Department] - Last Working Day [MM-DD-YYYY]
```

### 3.2 邮件模板
```
Dear Atomeocean HR Department,

I, [Your Full Name], [Your Position] of [Your Department], hereby confirm my formal resignation from Atomeocean, with my last working day being [MM-DD-YYYY].

I have completed the following:

All work handovers (please refer to the attached "Handover Checklist")
Returned all company assets 
Settled all financial matters
Kindly proceed with the necessary offboarding procedures.

Best regards,
[Your Full Name]
[Your Contact Number]
[Date: Month DD, YYYY]
```

## 4. 注意事项

1. 保密义务：离职后仍需遵守保密协议
2. 离职证明：办理完成后由HR统一发放
3. 工资结算：将在最后工作日后的15个工作日内完成

## 5. 常见问题
### Q：离职申请提交后可以撤销吗？

A：不可撤销

### Q：邮箱数据如何保存？

A：可提前通过邮箱归档功能备份重要邮件
