# H1b Transfer轻量工作服务

> [!tip] 服务简介
> Atomeocean为持有有效H1b的员工提供轻量工作服务，帮助满足H1b对实际美国工作经历的合规要求。

## 适用条件

申请本服务前，请确认以下条件均已满足：

1. 持有有效的H1b批准通知（I-797）
2. 当前H1b授权期限未过期
3. 拟从其他雇主Transfer至Atomeocean，或已完成Transfer流程

> [!WARNING] 注意
> H1b Transfer要求新雇主在您入职前完成LCA备案并向USCIS提交I-129申请。收到Receipt Notice后即可开始为Atomeocean工作（H1b Portability条款），无需等待最终批准。

## 服务交付内容

购买后您将获得

1. **H1b Transfer申请支持** — Atomeocean作为新雇主，完成LCA备案及I-129表格提交，协助您完成Transfer全流程
2. **专属信息页面** — 在Atomeocean Logbook上获得一个受密码保护的个人信息页面，记录您的雇佣信息、薪资及工作状态
3. **指定Supervisor** — 分配一名专属负责人，负责管理您的雇佣关系，并在签证申请等场景下提供雇主证明支持
4. **雇主证明支持** — Atomeocean可为您出具雇佣证明信，供签证申请、银行开户等场景使用

## 服务流程

1. **提交申请** — 点击上方按钮完成下单，填写基本信息
2. **信息收集** — 工作人员联系您收集I-797批准通知、近期pay stubs及联系方式
3. **签署合约** — 双方签署Atomeocean工作合约
4. **LCA备案** — Atomeocean向美国劳工部（DOL）提交Labor Condition Application
5. **I-129提交** — LCA批准后，向USCIS提交H1b Transfer申请（I-129）
6. **页面开通** — 在Logbook上为您开通专属信息页面，设置登录密码
7. **持续跟进** — Supervisor持续跟踪您的H1b状态，确保合规

## 常见问题

**Q：收到Receipt Notice前可以开始工作吗？**

不可以。需等到USCIS发出I-129收据通知（I-797C）后，方可依据H1b Portability条款为Atomeocean工作，无需等待最终批准。

**Q：Supervisor是否可以回应签证面签的雇主核查？**

可以。您的Supervisor可以通过邮件确认雇佣关系。具体请求方式请参考[负责人制度](/policy-document/staff/supervisor-policy.md)。

**Q：Supervisor的信息如何填写到签证申请表中？**

请参阅[在申请签证时如何填写Supervisor信息](/policy-document/staff/supervisor-choice.md)了解详细指引。

**Q：H1b Transfer申请需要多长时间？**

常规处理从数周到数月不等。如需加急，可申请Premium Processing，USCIS将在15个工作日内出具结果（额外费用由双方协商承担）。

**Q：购买后多久可以启动LCA申请？**

通常在完成信息收集及合约签署后的3个工作日内启动LCA备案。
