# CPT轻量工作服务

> [!tip] 服务简介
> Atomeocean为持有有效CPT授权的F-1学生提供轻量工作服务，帮助满足CPT对实际工作经历的合规要求，同时满足学校课程实践的学分需求。

## 适用条件

申请本服务前，请确认以下条件均已满足：

1. 持有有效的F-1学生签证身份
2. 已获得学校DSO签发的CPT授权I-20
3. CPT授权处于有效期内（未过期）
4. 所学专业与工作内容具有合理关联性

> [!WARNING] 注意
> CPT要求工作内容与学生的课程或专业学习直接相关。购买本服务前，请先确认您的学校已批准CPT授权，并确保Atomeocean的工作内容与您的专业方向匹配。

## 服务交付内容

购买后您将获得

1. **专属信息页面** — 在Atomeocean Logbook上获得一个受密码保护的个人信息页面，记录您的雇佣信息、薪资及工作状态
2. **指定Supervisor** — 分配一名专属负责人，负责管理您的雇佣关系，并在签证申请等场景下提供雇主证明支持
3. **雇主证明支持** — Atomeocean可为您出具雇佣证明信（Offer Letter / Employment Verification Letter），供学校CPT申请、签证续签等场景使用

## 服务流程

1. **提交申请** — 点击上方按钮完成下单，填写基本信息
2. **信息收集** — 工作人员联系您收集CPT I-20信息、学校录取证明及联系方式
3. **出具Offer Letter** — Atomeocean为您出具正式的Offer Letter，供学校DSO审核CPT申请
4. **签署合约** — 双方签署Atomeocean工作合约
5. **页面开通** — 在Logbook上为您开通专属信息页面，设置登录密码
6. **持续跟进** — Supervisor持续跟踪您的CPT状态，确保合规
