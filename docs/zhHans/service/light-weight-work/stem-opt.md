# STEM OPT轻量工作服务

> [!tip] 服务简介
> Atomeocean为持有有效STEM OPT的员工提供轻量工作服务，帮助满足STEM OPT对实际美国工作经历的合规要求。

## 适用条件

申请本服务前，请确认以下条件均已满足：

1. 持有有效的STEM OPT EAD卡
2. 当前处于STEM OPT授权期内（未过期）
3. 美国学位专业属于STEM领域

> [!WARNING] 注意
> STEM OPT要求雇主与员工共同签署I-983表格并提交DSO备案。购买本服务后，Atomeocean将作为雇主完成该流程。

## 服务交付内容

购买后您将获得

1. **专属信息页面** — 在Atomeocean Logbook上获得一个受密码保护的个人信息页面，记录您的雇佣信息、薪资及工作状态
2. **指定Supervisor** — 分配一名专属负责人，负责签署和管理您的I-983表格，并在签证申请等场景下提供雇主证明支持
3. **I-983签署** — Atomeocean将与您共同完成I-983表格的签署，并协助您提交给学校国际学生办公室

## 服务流程

1. **提交申请** — 点击上方按钮完成下单，填写基本信息
2. **信息收集** — 工作人员联系您收集EAD卡信息、学历证明及联系方式
3. **签署合约** — 双方签署Atomeocean工作合约
4. **I-983签署** — 与分配的Supervisor共同完成I-983表格，提交给您的学校DSO备案
5. **页面开通** — 在Logbook上为您开通专属信息页面，设置登录密码
6. **持续跟进** — Supervisor持续跟踪您的STEM OPT状态，确保合规

## 常见问题

**Q：Supervisor是否可以回应签证面签的雇主核查？**

可以。您的Supervisor可以通过邮件确认雇佣关系。具体请求方式请参考[负责人制度](/policy-document/staff/supervisor-policy.md)。

**Q：Supervisor的信息如何填写到签证申请表中？**

请参阅[在申请签证时如何填写Supervisor信息](/work-visas/resource/supervisor-choice.md)了解详细指引。

**Q：STEM OPT到期后服务如何处理？**

服务随STEM OPT到期自动终止。如您申请了H1b并获批，可咨询转换为H1b轻量工作服务。

**Q：购买后多久可以完成I-983签署？**

在完成信息收集后的3个工作日内完成。
