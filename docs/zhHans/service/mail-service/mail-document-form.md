# 文件寄送服务

本页面用于说明 **从Atomeocean寄送文件的标准流程**。  
目前我们提供两种 USPS 文件寄送方式，用户可根据时效和需求自行选择。

## 一、服务概览

当前支持以下两种文件寄送服务：

- **USPS 平邮（免费）**
- **USPS First Class（付费快邮）**

两种服务在寄送流程上基本一致，主要区别在于 **邮寄方式、时效以及费用结构**。

## 二、USPS 平邮（免费寄送）

### 服务说明

USPS 平邮适用于 **对寄送时效要求不高的文件寄送需求**。

- 使用 USPS 标准平邮服务
- 不收取任何人工处理费用
- 由 Atomeocean 协助统一寄出

### 费用说明

不收取人工处理费，也不收取邮寄费用。

> 该服务不向用户收取任何费用。

### 注意事项

- 平邮时效相对较慢且无法追踪，具体到达时间以 USPS 实际投递为准
- 不建议用于紧急或时效性较强的文件

## 三、USPS First Class（付费快邮）

### 服务说明

USPS First Class 适用于 **需要更快寄送速度或更高优先级处理的文件**。

- 使用 USPS First Class Mail
- 由工作人员进行人工处理、打包与寄送
- 提供更快的邮寄时效

### 费用说明

USPS First Class 的费用由两部分组成：**固定人工处理费**与**实际邮寄费用**。人工处理费为固定金额，邮寄费用为当前标准文件邮寄费用（随文件重量与目的地浮动）。

当前报价以[文件寄送产品页](/service/mail-service/service-mail?spec=first-class)上显示的金额为准——该页价格直接读取产品数据，本页不再复述具体数字，以免调价后两处对不上。

## 五、其他说明

- 所有文件均从 **Atomeocean 纽约总部**统一寄出
- 邮寄时效受 USPS 实际投递情况影响
- 如有特殊需求或疑问，请提前与相关负责人沟通确认
