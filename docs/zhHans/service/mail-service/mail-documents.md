# 过期-Atomeocean邮寄文档 Mail Documents

本文已经过期，请参考[Atomeocean寄送文件标准流程](mail-document-sop.md)


#### 邮寄服务流程

1. 确认邮寄需求
   * 提供文件的类型、数量，以及收件人详细信息（包括姓名、地址、联系电话）。
   * 确认邮寄的优先级（普通邮寄或加急邮寄）。
2. 填写邮寄申请表
   * 通过[指定邮件模板](mail-service-tool.md#邮件模板)发送申请
   * 必须包含以下信息：
   
     1. 发件人信息（默认atomeocean纽约总部地址）。
     2. 收件人详细地址（包括邮政编码）。 
     3. 邮寄方式（例如 USPS 普通邮件、快递服务等）。
3. 审批与费用核算
   * 公司核实申请信息后，计算邮寄费用。
     * 邮寄费用取决于邮寄方式、文件重量和服务商劳务费(Labor Cost)。
   * 将邮寄费用与预计到达时间反馈给申请人进行确认。
4. 文件打包与邮寄
   * 确保文件安全包装，必要时使用防水、防损的信封或文件袋。
   * 通过选定的邮寄方式（如 USPS、FedEx）寄出。
   * 邮寄完成后，生成跟踪编号（Tracking Number）。
     * 美国境内普通平信邮寄服务可能没有跟踪编号。
5. 发送邮寄通知
   * 邮寄完成后，通过邮件或内部消息通知申请人，包括以下内容：
     * 文件寄出日期。
     * 文件跟踪编号。
     * 预计送达时间。
6. 跟踪与确认
   *	邮件服务商会提供跟踪链接，方便申请人通过跟踪编号实时查看邮寄状态。
   *  邮寄成功后，申请人需确认文件是否已送达。
