# GitHub Issue使用方法

## 使用方法
进入code repository，例如[后端codebase](https://github.com/foo-tech/foo-back-end)

### 处理Issue
点击Issues tab，出现的Issue列表即为待做的任务

### 创建Issue
点击Issues tab，点击屏幕右侧绿色`New Issue`按钮创建Issue。

首先选择Issue模板，可以选择已有模板或最下方Open a blank issue不选择模板。

进入Issue编辑页面后，输入标题并完成描述部分
